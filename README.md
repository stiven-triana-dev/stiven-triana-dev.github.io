# Portafolio de Stiven Triana

Sitio personal de **Neider Stiven Triana Neira**, desarrollador backend junior (Java · Spring Boot · PostgreSQL) en San Gil, Colombia.

🌐 **En línea:** https://stiven-triana-dev.github.io

## Tecnologías

- React + Vite
- CSS propio con modo claro y oscuro
- Publicado en GitHub Pages con GitHub Actions en cada push a `main`

## Correr en local

```bash
npm install
npm run dev
```

## Editar contenido

Los textos de proyectos, trayectoria y habilidades están en `src/data.js`. La hoja de vida descargable está en `public/`.
